# ScrollnScroll (Endless Toilet Paper) 🧻

An absurdist, addictive, and viral-oriented Android game developed with Jetpack Compose.

## 🌟 Overview
- **Concept**: Endless Toilet Paper scrolling game designed for doomscrollers.
- **Theme**: Absurdist / Meme / Pop-Art Neo-Brutalism.
- **Core Loop**: Swipe to scroll 999,999 km of toilet paper, unlock evolving skins (Golden 24K, Crab Noodle Soup, $100 USD, Galaxy), trigger BURNING OVERDRIVE combos, earn satirical certificates, and climb the Global & Country Leaderboard.

## 🛠️ Tech Stack
- **Language**: Kotlin 2.x
- **UI Framework**: Jetpack Compose (Material 3, Custom Canvas Physics)
- **Architecture**: MVVM + Clean Architecture + StateFlow
- **Storage**: AndroidX DataStore Preferences
- **Audio & Haptics**: SoundPool ASMR + Haptic Engine
