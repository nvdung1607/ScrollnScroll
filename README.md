# ScrollnScroll (Endless Toilet Paper) 🧻

An absurdist, addictive, and viral-oriented Android game developed with Jetpack Compose.

## 🌟 Overview
- **Concept**: Endless Toilet Paper scrolling game designed for doomscrollers.
- **Theme**: Absurdist / Comic Pop-Art / Vietnamese Meme Satire.
- **Core Loop**: 
  - Swipe in any direction ($360^\circ$ omnidirectional physics) to roll out endless meters of toilet paper.
  - Odometer real-time distance tracking.
  - High-speed scrolling ($> 8\text{ SPS}$) triggers **BURNING OVERDRIVE** with fire borders and speed multipliers.
  - Authentic Vietnamese **GIẤY KHEN** (Certificate of Merit) vector generated on milestones with 1-click Story Share and Gallery Download.
  - Unlock 9 evolving custom skins (Rau Má 36, Comic Meme, Royal Gold 24K, Crab Noodle Soup, $100 USD, Mummy, Space Galaxy, Ultimate Diamond).
  - Global & Country Leaderboard ranking.

## 🛠️ Tech Stack
- **Language**: Kotlin 2.x
- **UI Framework**: Jetpack Compose (Material 3, Custom Canvas Physics & Traditional Certificate Vector Drawing)
- **Architecture**: MVVM + Clean Architecture + StateFlow
- **Storage**: AndroidX DataStore Preferences
- **Audio & Haptics**: SoundPool ASMR + Haptic Engine
- **Sharing**: Android MediaStore API & FileProvider
